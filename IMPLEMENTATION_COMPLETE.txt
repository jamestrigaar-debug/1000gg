IMPLEMENTATION DETAILS
================================================================================

1. EVENT ID VALIDATION

Function: validateEventData(data)

Purpose:
  - Ensures all events have unique IDs
  - Catches data entry errors at load time
  - Prevents silent failures from duplicates

How it works:
  1. Collects all events from all 5 categories
  2. Checks each event for missing ID field
  3. Detects duplicate IDs
  4. Reports all errors at once
  5. Throws error if any issues found

Benefits:
  - Catches bugs early (at load time)
  - Clear error messages for debugging
  - Safe error handling (doesn't crash app)
  - Exported for use in other engines

2. CONTEXT SCHEMA

Constant: CONTEXT_SCHEMA

Purpose:
  - Documents the context object structure
  - Used in requirement checking
  - Helps new engine developers

Fields documented:
  - age (number)
  - role (string: Star|Starter|Rotation|Bench)
  - yearsAtClub (number)
  - reputation (number)
  - performance (string: Sensational|Overperformed|Met Expectation|Underperformed|Flop)
  - contractYears (number)
  - gamesMissed (number)
  - trajectory (string)
  - intlCaps (number)
  - intlRetired (boolean)
  - wonHonour (boolean)
  - season (number)

Benefits:
  - Reference documentation for developers
  - Prevents bugs from missing fields
  - Enables proper context building in other engines
  - Exported for use in other engines

3. EFFECT SCHEMA

Constant: EFFECT_SCHEMA

Purpose:
  - Documents the effect object structure
  - Used in effect application
  - Helps new engine developers

Fields documented:
  - attrChange (object with key and delta)
  - attrChange2 (object with key and delta)
  - derivedChange (object with agility and balance)
  - rep (number)
  - fame (number)
  - wealth (number)
  - role (string: up|down)
  - forceTransfer (boolean)
  - pillars (object with pillar names and deltas)
  - flag (string)
  - carryOver (boolean)
  - carryOverLog (string)
  - contract (number)
  - intlCaps (number)
  - intlGoals (number)
  - setIntlRetired (boolean)
  - retireNow (boolean)
  - finalSeason (object with destination and note)
  - epilogue (string)
  - goals (function or number)
  - assists (function or number)
  - positionChange (string)
  - injuryProne (number)

Benefits:
